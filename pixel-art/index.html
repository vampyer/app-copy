Using 16x16 pixel art in your engine

Godot 4: import the sprite sheet, then in the Import tab set Filter to Nearest (or set Project Settings → Rendering → Textures → Default Texture Filter to Nearest) so pixels stay sharp. Use a TileSet with 16x16 tiles for the dungeon tileset and a NinePatchRect for UI panels.

Unity: set each texture to Sprite (2D and UI), Filter Mode Point (no filter), Compression None and Pixels Per Unit 16. Slice the sheet with Sprite Editor → Slice → Grid By Cell Size 16x16.

GameMaker: create a sprite from the sheet with Import Strip Image (16x16 frames), or a tile set with 16x16 tiles. Turn off texture interpolation in Game Options.

RPG Maker: use the larger scaled PNGs or sprite sheets, which are scaled with nearest-neighbor so they stay crisp.
